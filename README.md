# ⚽🏀 Analizador IA de Partidos

![GitHub Pages](https://img.shields.io/badge/GitHub-Pages-blue)
![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?logo=javascript&logoColor=black)

Aplicación web inteligente para analizar probabilidades de encuentros deportivos de fútbol y baloncesto utilizando algoritmos de IA.

## 🚀 Características

- 📊 **Análisis IA** de partidos en tiempo real
- ⚽ **Fútbol**: Champions League, Premier League, La Liga, etc.
- 🏀 **Baloncesto**: NBA, EuroLeague, Liga ACB
- 🤖 **Modelo predictivo** basado en estadísticas
- 🎯 **Predicciones** con porcentajes de probabilidad
- 📈 **Estadísticas detalladas** por equipo
- 📱 **Diseño responsive** (funciona en móviles y desktop)

## 🎮 Cómo usar

1. **Selecciona** un deporte (Fútbol o Baloncesto)
2. **Elige** una liga disponible
3. **Selecciona** dos equipos diferentes
4. **Haz clic** en "Analizar Partido con IA"
5. **Revisa** las predicciones y estadísticas
